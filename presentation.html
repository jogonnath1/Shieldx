Project Overview & Goal

  • Description: ShieldX is a comprehensive mobile application bridging the gap between citizens and law enforcement (Sylhet Metropolitan Police).
  • Goals: Empower citizens to report crimes, track complaints in real-time, and trigger SOS alerts. Provide police with a powerful command dashboard.
  • Motivation: Enhance response times, ensure transparency in crime reporting, and improve citizen safety during emergencies.

Functional Requirements

  • Citizen Portal: Secure Onboarding, Smart Complaint Submission with Evidence Upload, Real-time Tracking, SOS Emergency Button, Interactive Police Map.
  • Admin Portal: Command Dashboard with Live Analytics, Complaint Management, Officer Dispatch, Live SOS Panel.

Non-Functional Requirements

  • Operating System Environment: Cross-platform mobile environment (Android and iOS).
  • Frameworks and Tools:
    • UI Framework: Flutter (Dart)
    • Backend & Database: Supabase (PostgreSQL with Row Level Security)
    • State Management & Routing: Riverpod, GoRouter
    • Mapping Services: flutter_map with OpenStreetMap Tiles

Discussion / Conclusion

  • Limitations: Requires an active internet connection for real-time tracking; relies heavily on device GPS accuracy.
  • Restrictions: Currently customized and localized specifically for the Sylhet Metropolitan Police jurisdiction.
  • Future scope and improvements: Implementation of AI-based predictive crime mapping, integration with national emergency hotline (999), and offline SOS via SMS fallback.
